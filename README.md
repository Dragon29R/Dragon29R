### Key Projects

#### [Automated Dressing Saturation Analysis](https://github.com/Fraunhofer-or-Repo-Link)
*M.Sc. Dissertation | FEUP & Fraunhofer Portugal AICOS*
- **Description:** Modular computer vision pipeline to quantify saturation levels in chronic wound dressings.
- **My Contributions:** Implemented semantic segmentation and transfer learning pipelines in PyTorch Lightning & MMSegmentation; built data augmentation pipelines; evaluated Dice/mIoU scores.
- **Stack:** Python, PyTorch, MMSegmentation, OpenCV, Scikit-learn.

#### [Zyvera / Lyra – AI Outfit Recommendation App](https://github.com/owner/zyvera-repo)
*Project Management Laboratory (LGP) | FEUP*
- **Description:** Full-stack mobile platform generating personalized outfit recommendations via AI.
- **My Contributions:** Built cross-platform mobile frontend with Flutter & Dart; implemented authentication, user preference state management, and integrated backend REST APIs.
- **Stack:** Flutter, Dart, TypeScript, REST APIs, Git.

#### [3D Spatial Normalization & Immersive Environments](https://github.com/owner/pi-repo)
*Integrator Project (PI) | FEUP*
- **Description:** Automated geometry parsing and bounding box calculator across heterogeneous 3D formats.
- **My Contributions:** Developed parsing algorithms, normalization logic, and JSON schema metadata validation pipelines.
- **Stack:** Python, 3D Geometry Algorithms, JSON Schemas.
